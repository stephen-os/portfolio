## Same structural rules as posts

Each project owns a folder under `content/projects/`. Cover images and any inline assets sit next to `index.mdx` and get referenced with relative paths.

```bash
content/projects/temp-project/
├── index.mdx
└── cover.jpg
```

## Optional fields

The `ProjectFrontmatter` schema accepts:

- `github` — repo URL, renders as a "View Source" button
- `demo` — live demo URL, renders as a "Live Demo" button
- `featured` — boolean, surfaces the project on the homepage

This temp project has none set, so the page stays minimal.
